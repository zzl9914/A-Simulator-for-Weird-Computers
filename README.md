# 原型机模拟器

五台按原型编码和容量做的模拟器。磁鼓等待和读卡没有做进来。

- **Сетунь（1958）**：平衡三进制，单地址。快存 162 个九位短字，分成三区；磁鼓 36 区，每区 54 字。结果留在寄存器 S，条件转移看符号 `w`。
- **Сетунь-70（1970）**：另一套三进制机。程序放在页里，是一串六位 трайт。栈上的一格是三个 трайт。一级内存 27 页，每页 81 槽：9 页 ОЗУ、18 页 ПЗУ。三个 приписки 指出当前打开的页。磁鼓 243 页。
- **ENIAC（1945）**：十中取一。每位十个灯里亮一个。20 个十位累加器。程序是一串脉冲，对应真机上的接线。
- **IBM 650（1954）**：二五进制，磁鼓 2000 字。两盏里亮一盏表示 0 或 5，五盏里亮一盏表示 0 到 4。每条指令自带下一条的地址。
- **IBM 1401（1959）**：8421 BCD，1400 个字符。地址超过 999 时百位加 A 区位。打印区是 201–332。字段从个位往左，直到字标。

二五进制不是 5421。5421 里的 3 是权 2 和权 1 同时亮；二五进制里的 3 只亮标着 3 的那一盏。

## 本地运行

汇编器是 C++ 后端。源程序按机器放在 `programs/setun`、`programs/setun70`、`programs/eniac`、`programs/ibm650`、`programs/ibm1401`。这些目录在仓库里是空的，把自己的 `.asm` 放进去之后，前端会打开文件，交给 `radixcc` 编译，再在页面上单步。

```bash
npm install
cmake -S compiler -B compiler/build
cmake --build compiler/build
npm run dev
```

浏览器打开 [http://127.0.0.1:43127](http://127.0.0.1:43127)。

```bash
npm test
```
