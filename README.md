# 原型机模拟器

五台老机器，按各自的编码、容量和指令来跑。磁鼓转到哪一位、读卡要等多久，没有做进来。

- **Сетунь（1958）**：平衡三进制，单地址。快存 162 个九位短字，磁鼓 36 区。结果留在 S，条件转移看上一趟的 w。
- **Сетунь-70（1970）**：另一台三进制机。程序是页里的音节，栈上的一格是三个 трайт。27 页一级内存，磁鼓 243 页。
- **ENIAC（1945）**：十中取一，20 台十位累加器。没有存放程序的内存，一行就是一根接线。
- **IBM 650（1954）**：二五进制，2000 字磁鼓。指令自己带着下一条的地址。7 是「5」加「2」，不是 5421。
- **IBM 1401（1959）**：8421 BCD，1400 个字符。字段从个位往左直到字标，正负号写在个位的区位上。

## 运行

双击 `start.bat`。它会安装依赖，并在还没有汇编器时用 g++ 编出 `compiler/build/radixcc.exe`。

也可以手动：

```bash
npm install
cmake -S compiler -B compiler/build
cmake --build compiler/build
npm run dev
```

浏览器打开 [http://127.0.0.1:43127](http://127.0.0.1:43127)。程序放在 `programs/` 下对应机器的目录里；目录是空的，就从一张白纸写起。

```bash
npm test
```
